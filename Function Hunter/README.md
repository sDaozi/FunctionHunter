# 函数猎手 · Function Hunter

杭州学军中学教育集团文渊中学 · 自然语言编程创意实践 · 五一项目

## 简介

一款用**数学函数图像作为激光路径**的射击游戏。在屏幕底部输入函数表达式（如 `x^2`、`sin(x)*3`、`2x+1`），按下回车，激光便沿着该函数的图像绘制并击中曲线经过的所有敌人。

无限街机模式：敌人不断从上方下落，越打越快。考验你的函数直觉与反应速度。

## 启动

**双击 `index.html` 即可在 Chrome / Edge 浏览器运行**，无需任何安装。

## 玩法

1. 屏幕底部中心是数学坐标系原点 (0, 0)
2. 上方有敌人按数学坐标下落
3. 在底部输入框输入函数（如 `x^2`），可看到半透明实时预览
4. 按 Enter 发射激光，曲线会击中**距离曲线 0.5 单位内**的所有敌人
5. 敌人触底会扣护盾，3 点护盾归零游戏结束

## 支持的语法

- 四则运算：`+ - * /`
- 幂：`^` 或 `**`（如 `x^2`、`2^x`）
- 隐式乘法：`2x` 自动等于 `2*x`
- 函数：`sin cos tan asin acos atan sqrt abs log ln exp floor ceil round`
- 常数：`pi`、`e`
- 绝对值：`abs(x)` 或 `|x|`
- 括号：`(x-2)^2 - 3`

## 战术建议

- **一次函数** `2x+3`：直线穿过对角线敌人
- **二次函数** `x^2 - 4`：抛物线扫两侧底部
- **平移变换** `(x-2)^2 + 1`：把抛物线顶点移到 (2, 1)
- **反比例** `4/x`：双曲线打对角分布
- **三角函数** `sin(x)*3`：正弦波横扫一行多个敌人

## 模式

- **无限街机**：随机生成敌人，越玩越难，拼高分
- **沙盒练习**：自由输入多条函数，观察图像（彩色叠加）

## 计分规则

- 普通敌人 100 分 / 精英 300 / BOSS 1000
- 一次发射多杀触发**连击**（×N），分数翻倍
- 最高分 localStorage 持久化

## 技术

- 纯原生 HTML / CSS / Canvas / JavaScript
- 自研 shunting-yard 表达式解析器（含隐式乘法、一元负号等高级特性）
- 数学坐标 ↔ 屏幕像素 双向映射
- 点到曲线最短距离碰撞检测
- 60fps 主循环
- 不依赖任何外部库，file:// 协议下完美运行

## 学科价值

- ✅ 直观理解函数图像（一次/二次/反比例/三角/指数对数）
- ✅ 函数变换：平移、缩放、对称
- ✅ 函数与几何位置的关系
- ✅ 表达式语法（运算符优先级、括号、隐式乘法）
